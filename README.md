# WhatsApp seguro — Validación, ayuda y publicación (M07)

Sobre la app del repositorio [m09-whatsapp-seguro](https://github.com/USUARIO/m09-whatsapp-seguro):

- `tests/` → batería de pruebas que valida el servidor desplegado en Proxmox.
- `docs/` → página de GitHub Pages (descarga + QR) y ayuda en HTML.

Página publicada: https://USUARIO.github.io/m07-publicacion/

## Ejecutar las pruebas

```bash
cd tests
./run-tests.sh ws://IP_PROXMOX:8080
```
